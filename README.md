# Cancer Patient Healthcare Analytics

## Project Overview

This project analyzes 100,000 cancer patient records from India using Microsoft Excel.

The analysis focuses on patient demographics, cancer prevalence, treatment patterns, hospital workload, survival outcomes, and diagnosis trends.

## Objectives

- Analyze patient demographics and geographic distribution
- Identify common cancer types
- Analyze cancer stages and treatment patterns
- Compare cancer types with treatment types
- Evaluate hospital workload and outcomes
- Analyze survival by cancer type, stage, treatment, gender and age
- Study diagnosis trends over time
- Build an interactive Excel dashboard

## Tools Used

- Microsoft Excel
- PivotTables
- PivotCharts
- Excel formulas
- Slicers
- Dashboard visualizations

## Key Results

- Total patients: 100,000
- Hospitals: 10
- Cancer types: 9
- Average patient age: 53.90 years
- Recorded alive patients: 36,423
- Recorded deceased patients: 63,577
- Recorded survival rate: 36.42%
- Most common cancer type: Breast Cancer
